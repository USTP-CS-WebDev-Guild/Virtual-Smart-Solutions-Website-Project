# Learn by using the working system

Start with START-HERE.md. Each lesson makes one small change with a result you can observe.

1. [First source change](01-first-change.md) — locate and edit a component.
2. [Request to database](02-request-to-database.md) — trace a real save and rejection.
3. [Business transaction](03-transaction.md) — conversion and retry safety.
4. [Live updates and permissions](04-live-and-private.md) — two tabs, two roles.
5. [Review and release](05-review-and-release.md) — collaborate and deploy safely.

Work in a branch. Each lesson ends with evidence, not a checkbox saying you read the code. You do not need cloud credentials for lessons 1–4.
